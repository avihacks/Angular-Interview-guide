How to Upload & Host on GitHub

1 Create a New GitHub Repository

Go to github.com, sign in, click the "+" icon in the top right, and select New repository. Name it angular-interview-guide and make it Public.

2 Save this Code File

Save this single generated HTML file to your local computer as index.html.

3 Upload via GitHub Web Interface

Inside your newly created repository, click the link that says uploading an existing file. Drag and drop your index.html file into the browser window and commit changes.

4 Enable GitHub Pages Hosting

Go to your repository's Settings tab -> Pages in the left sidebar. Under Build and deployment source, select Deploy from a branch, choose the main branch and root folder / (root), then click Save. Your website will be live in under a minute!
